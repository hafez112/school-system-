# School System - Monorepo

إدارة المدارس الأهلية باستخدام PHP 8.3 وMySQL 8.4. المرحلة الحالية: أساس المشروع ومصادقة المستخدمين والصلاحيات.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env`، وغيّر كلمات مرور قاعدة البيانات و`JWT_SECRET` إلى قيم عشوائية خاصة بك. لا ترفع `.env` إلى Git.
2. أنشئ سر JWT: `php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"`.
3. شغّل: `docker compose up -d --build`.
4. أنشئ أول مدير نظام بكلمة مرور قوية: `docker compose exec api php bin/create-admin.php admin@example.com 'مدير النظام' 'ضع-كلمة-مرور-قوية-هنا'`.
5. افحص الخدمة: `curl http://localhost:8080/health`.

## واجهات المصادقة

- `POST /api/v1/auth/login` — JSON: `email`, `password`.
- `POST /api/v1/auth/refresh` — JSON: `refresh_token`. يُدوّر رمز التجديد ويُبطل السابق.
- `POST /api/v1/auth/logout` — Bearer access token وJSON اختياري يحوي `refresh_token`.
- `POST /api/v1/auth/me` — Bearer access token لإرجاع الحساب والأدوار والصلاحيات.

رمز الوصول JWT قصير العمر (15 دقيقة افتراضيًا). رمز التجديد عشوائي، لا يُخزن إلا تجزئته، ويُبطل عند تدويره أو تسجيل الخروج. غيّر `JWT_SECRET` قبل أي نشر. للإنتاج استخدم HTTPS واضبط الأسرار في منصة النشر.

## الأدوار والصلاحيات

تُنشأ الأدوار: مدير النظام، مدير المدرسة، وكيل المدرسة، المعلم، الموظف، ولي الأمر، والطالب. الصلاحيات ذات أسماء قابلة للتوسعة في جداول منفصلة. جميع صلاحيات النظام مخصصة افتراضيًا لمدير النظام فقط؛ ويجب تعيين صلاحيات الأدوار الأخرى وفق سياسة المدرسة قبل فتح واجهاتها. سجلات الدخول الناجح والفاشل والخروج تحفظ في `audit_logs`.

تهيئة SQL تُنفذ تلقائيًا على قاعدة بيانات جديدة فقط. عند وجود volume قديم نفّذ ملف `packages/database/init/002_auth_and_rbac.sql` يدويًا مرة واحدة.
